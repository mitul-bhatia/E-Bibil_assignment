# Interface

Dark chat interface selected by the user. Quiet charcoal-green surfaces, pale green action color, DM Sans, and a fixed library sidebar. The primary path is question → answer → original source passage. Sources are readable rows, not decorative cards. Show the real index state. The empty conversation offers questions; unknown answers and provider errors are separate states. Mobile collapses the library behind a labelled menu. Honor reduced motion and keep keyboard focus visible.
